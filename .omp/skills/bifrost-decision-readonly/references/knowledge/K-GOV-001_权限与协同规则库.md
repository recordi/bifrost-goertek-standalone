# K-GOV-001 权限与协同规则库

## 元数据
- knowledge_level: D（团队模拟/项目设计）
- source_type: 团队模拟/项目设计
- knowledge_version: KNOWLEDGE-v1.1
- 不得表述为歌尔内部真实制度或真实生产知识
- **本库只保存权限、协同规则和状态机定义；确认实例的具体状态从 validation_results 动态读取。**

## 六角色关注范围

### 厂长（factory）
- 全厂/多产线影响
- 严重度评估
- 交付风险
- 待决策事项
- 不展示冗长停机明细

### 线长（line）
- 本线 OEE 分解
- 停机、当班不良、物料影响
- 立即行动和执行顺序
- 责任协同

### 质量（quality）
- 不良类型分布
- 冻结信息
- 复检与隔离建议
- 不得在无测量点时生成 SPC/Cpk 结论

### 设备（equipment）
- 停机明细和 Pareto
- 必须说明 MTBF/MTTR 证据不足

### 工艺（process）
- 换产、工艺偏移
- 缺陷与质量关系
- 不得把相关性表述为已证实因果

### 供应链（supply）
- 物料缺口和冻结
- 区分"缺口物料"和"冻结物料"
- 不得把两者合并为同一原因

## 高风险动作清单
1. 解除质量冻结
2. 修改指标公式或阈值
3. 调整排产计划
4. 修改交付承诺
5. 覆盖原始数据
6. 发布知识版本

以上动作只能生成待确认草稿，prohibited_auto_execute=true。

## 待确认状态机
```
[草稿生成] → [待确认] → [人工确认] → [执行]
                      → [人工驳回] → [关闭]
                      → [超时撤回] → [关闭]
```

当前状态：从 validation_results.decision_confirmation_map 动态读取各 confirmation 的 status 字段（可能值：待确认 / 撤回 / 已确认）。**不得硬编码确认状态。**

## 数据权限
- Aily 使用只读凭据访问业务数据
- 只允许对运行审计表追加日志
- 不得写回业务事实表（12/13/14/16/17 等模拟表）
- 确认草稿只写入草稿/控制表，状态固定为待确认
- 外部写入能力默认关闭
