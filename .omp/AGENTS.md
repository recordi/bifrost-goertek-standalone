# BIFROST 项目级上下文

## 项目名称
BIFROST 智能经营分析与决策闭环平台。

## 目标命题
利用企业数据和飞书能力，为不同岗位生成专属看板，完成洞察、预警、推送、任务协同、人工确认和复盘闭环。

## 六个业务角色
厂长、线长、质量、设备、工艺、供应链。角色是业务信息视图，不是 Oh My Pi 工程代理。

## 三条工程模拟产线
LINE-S01、LINE-S02、LINE-S03；它们来自工程化模拟拆分，不得描述为歌尔真实三条产线。

## 五个时间窗口
最近7班次、最近30班次、改善前、改善后、全部历史。

## 主要数据层
语义数据面、语义消费者、专业只读 Skill、决策编排、Overview/Event 双载荷和 UI 基线。

## 业务主线
自然语言需求 → 角色视图 → 洞察 → 预警 → 精准推送 → 任务协同 → 人工确认 → 复盘。

## 当前主运行目标
当前主运行目标是迁移后的 BIFROST 结构化合同链；`bifrost-decision-readonly` 仅为静态载荷回退能力，不是未来主链路。
