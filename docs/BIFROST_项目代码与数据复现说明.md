# BIFROST 项目代码与数据复现说明

## 1. 项目简介

BIFROST 是面向制造业岗位的数据洞察工作台。系统将生产、质量、设备、工艺和供应链信息放入同一套分析流程，支持：

- 三条产线横向比较
- 六类岗位视角切换
- 五种时间范围分析
- OEE、良率、停机、不良和物料缺口分析
- 数据治理和字段兼容性检查
- 事件证据下钻
- AI 问答和人工确认流程

项目中的数据均为公开、脱敏或团队模拟数据，适合原型验证和方案复现。

## 2. 代码结构

```text
bifrost-goertek/
├─ apps/
│  ├─ daemon/                 # 运行状态、治理提议和任务编排服务
│  ├─ runner/                 # 数据读取与分析服务
│  └─ web/                    # 联合工作台工程
├─ packages/contracts/        # 请求、响应、指标和数据集合同
├─ knowledge/                 # 角色、技能、设计规则和知识材料
├─ output/bifrost-ui-runtime/ # BIFROST 看板运行时源码与正式快照
│  ├─ src/                    # 页面和数据适配代码
│  └─ artifacts/              # Overview/Event 载荷
├─ test-inputs/               # 两份可复现测试数据
├─ fixtures/                  # 测试夹具
└─ docs/                      # 项目说明、设计和验收材料
```

页面使用统一载荷读取业务事实。页面显示的指标来自数据适配层和事实集，指标口径、证据引用和数据缺口一起传递到页面。

## 5. 进入系统后的操作顺序

### 第一步：选择角色

顶部角色栏提供六个岗位：厂长、线长、质量、设备、工艺、供应链。

角色决定页面关注点和 AI 回答范围：

| 角色 | 主要关注内容 |
|---|---|
| 厂长 | 全厂产线对比、重大异常、交付影响和待决策事项 |
| 线长 | 本线 OEE、停机、不良、物料和当班行动 |
| 质量 | 不良类型、良率、质量冻结、隔离和复检 |
| 设备 | 停机事件、停机组、故障 Pareto 和设备数据缺口 |
| 工艺 | 性能率、换产、工艺参数和 SPC 接入状态 |
| 供应链 | 物料缺口、可用量、冻结和工单影响 |

### 第二步：选择时间范围

可选择：

- 最近 7 个班次
- 最近 30 个班次
- 改善前
- 改善后
- 全部历史

时间范围变化后，趋势图、排名和指标卡片同步刷新。

### 第三步：选择产线

系统支持：

- 一号产线（LINE-S01）
- 二号产线（LINE-S02）
- 三号产线（LINE-S03）
- 三条产线同时勾选比较

厂长可使用三线对比和排行，线长可进入单线详情，其他岗位可按专业维度查看对应产线数据。

## 6. 页面使用说明

### 6.1 看板中心

看板中心提供当前范围的 KPI、趋势、排名和业务解读。

使用步骤：

1. 选择角色。
2. 选择时间范围。
3. 勾选一条或多条产线。
4. 查看 OEE 趋势和排名。
5. 点击产线进入详情。
6. 根据停机、不良、物料和事件继续下钻。

OEE 的业务含义是设备开动、运行速度和产出质量的综合表现。OEE 低时，需要继续查看停机和质量记录，页面中的 OEE 数值本身承担状态提示作用。

### 6.2 事件中心

事件中心用于处理异常事件。

以 `EVT-20251009-0001` 为例：

1. 打开事件中心。
2. 选择三号产线。
3. 打开黄金事件。
4. 查看 OEE、停机、不良和物料信息。
5. 切换六个角色，观察同一事件的不同关注重点。
6. 展开证据引用，查看来源记录。
7. 查看待确认事项。

涉及解除冻结、调整排产、修改阈值或修改交付承诺时，系统只生成待确认草稿，具体执行由有权限人员完成。

### 6.3 数据治理

数据治理页面分为三个视图：

- 总览：查看整体兼容性和治理状态。
- 缺陷详情：查看问题描述、影响范围和证据。
- 检测规则：查看字段映射、数据缺口、版本和关联检查。

六类数据缺陷包括缺失、重复、异常值、格式不一致、逻辑冲突和时效滞后。

兼容性问题包括：

- 换产规则 ID 缺失
- SPC/Cpk 数据未接入
- EquipmentID 不完整
- 工艺参数缺失
- 版本升级记录
- 事件、任务、确认和证据绑定问题

“未检测”表示当前数据合同缺少对应字段或检测样本，页面会同时说明影响范围。

### 6.4 管理配置

管理配置提供只读数据源查看、规则试算、权限角色和系统设置。

规则试算用于回答“如果调整标准，结果会发生什么”：

1. 选择候选指标规则。
2. 填写样本班次的开动率、性能率、质量率和产量。
3. 填写实际换产时间和标准换产时间。
4. 点击“试算影响”。
5. 查看达标、预警和严重状态变化。
6. 确认后生成审批草稿。

试算结果只属于候选规则草稿。正式规则发布需要人工确认并保留版本记录。

## 7. AI 助手使用方式

点击顶部“问 AI”或左侧“AI 助手”。系统会自动携带：

- 当前角色
- 当前产线
- 当前时间范围
- 当前事件
- 当前页面指标
- 数据版本和规则版本

可以直接提问：

```text
为什么三号产线最近七个班次的 OEE 低于目标？
```

```text
当前最需要优先处理的三个问题是什么？
```

```text
这次事件对质量和物料有什么影响？
```

```text
当前数据是否支持计算 Cpk？
```

回答应包含结论、指标、证据、数据缺口、建议动作和人工确认状态。

当前页面显示“演示数据 · AI 未连 · 只读”时，系统处于本地快照模式。此时看板、事件中心、数据治理和规则试算仍可使用，AI 问答需要先配置真实服务入口。录屏或提交材料中应按页面状态说明，不把静态内容描述成实时 AI 结果。

![质量视角：质量趋势与主要缺陷累计影响](figures/user-result-screens/02-quality-dashboard.png)

1. 切换到“质量”。
2. 查看质量率趋势。
3. 查看主要缺陷的数量和占比。
4. 先关注柱形较高的缺陷类型。
5. 再进入班次、工单和证据记录确认改善对象。

![数据治理：字段映射与数据缺口检查](figures/user-result-screens/03-data-governance.png)

1. 打开“数据治理”。
2. 查看问题类型和严重度。
3. 点击“查看”展开检测规则和影响范围。
4. 对需要业务处理的问题点击“生成草稿”。
5. 由管理员确认后进入后续处理。

图表说明：页面同时展示官方六类缺陷检测状态和当前数据兼容性检查。两者共同说明数据是否适合进入统一指标和看板流程。

### 8.4 管理配置：规则试算和版本控制

![管理配置：候选规则试算](figures/user-result-screens/04-management-config.png)

使用方式：

1. 打开“管理配置”。
2. 进入“规则管理”。
3. 修改候选规则的目标、预警和严重阈值。
4. 填写样本数据。
5. 点击“试算影响”。
6. 查看新旧规则的状态变化。
7. 需要正式应用时生成审批草稿。

图表说明：候选规则只用于影响预览，正式看板和历史事件继续使用已经发布的规则版本。

## 9. 外部数据复现流程

使用歌尔可脱敏企业数据进行测试时：

1. 将 `test-inputs/歌尔可脱敏企业测试数据集.xlsx` 作为输入文件。
2. 执行字段画像和字段映射。
3. 查看六类数据质量检查结果。
4. 确认产品、物料、项目、订单等关联字段。
5. 生成统一数据集和分析载荷。
6. 进入只读预览。
7. 确认结果后再生成新的页面载荷。

使用团队工程化模拟数据时：

1. 读取 `test-inputs/BIFROST_飞书导入数据包_v3_P0修复版_SIM-v2.2.xlsx`。
2. 读取现有 Overview/Event 载荷。
3. 验证三产线、黄金事件、停机明细和物料关联。
4. 从看板中心进入事件中心复现完整闭环。

原始数据只读使用。适配预览不会覆盖原文件，正式规则和历史事件也不会在试算阶段改变。

## 10. 常见问题

### 页面能打开但 AI 不能回答

检查顶部状态。如果显示“AI 未连”，说明当前只连接了本地快照。需要配置真实 AI 服务入口，并验证请求、响应和错误处理。

### 数据治理显示“未检测”

说明当前输入文件缺少对应检测字段或样本量。页面会保留这一状态，并给出影响说明。

### 规则试算结果能否直接发布

不能直接改变正式规则。试算结果先形成候选草稿，经过人工确认后才可以发布新规则版本。

### 如何切换到别的岗位

点击顶部角色按钮。产线、时间范围和事件上下文会继续保留，页面内容随角色切换。
